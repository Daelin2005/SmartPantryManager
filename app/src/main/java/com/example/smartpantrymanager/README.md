# Smart Pantry Manager

Smart Pantry Manger is an Android Application designed to help users keep
track of their kitchen in inventory and discover meals they can cook immediately

The app filters recipes based solely on the ingredients currently available 
in the pantry

Database Chosen: SQLite
Reason: 
SQLit was chosen because it is lightweight, built directly into Android
via 'SQLiteOpenHelper', requires no external server setup, and provides fast local
data persistence for the CRUD operations on mobile devices

Setup instructions:

1) Download This repository
2) Open the project folder in Android Studio
3) Sync the project with Gradle Files
4) Connect an Android device or you can start an android virtual device 
5) Click the Run button to build and launch the application
